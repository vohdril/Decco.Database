## Anomalia
 
ROOT ENTITY. Each row is a record of the DeCCO anomaly catalog. It gathers the ontological classification (class, layer, matter, mechanisms), the Brazilian classification (cognition, dangerousness), the measurable Theta markers and the operational state. Id starts at 1000; the public identity is CodigoSCP.
 
| Column | Type | Nullable | Description |
|---|---|---|---|
| `Id` | int | no | Internal Id, IDENTITY starting at 1000. It is NOT the public identity — the contract exposes CodigoSCP (IdToCode pattern). |
| `CodigoSCP` | varchar(50) | no | Public, stable identity of the anomaly (e.g. SCP-1001). External consumers reference the record by this code. |
| `NomeComum` | nvarchar(255) | no | Common name, readable by operators (e.g. Proteu - O Metamorfo Complexo). |
| `Descricao` | nvarchar(MAX) | no |  |
| `ClasseObjetoId` | int | no | Containment class. Through Cat_ClasseObjeto.NivelAcessoMinimo, it determines the clearance needed to see this anomaly. |
| `CamadaOntologicaId` | int | no | Plane the anomaly operates on (THETA/PSI/PHI/OMEGA). Together with the matter type, it defines whether it falls into the Sigma slice. |
| `TipoMateriaId` | int | no | Material composition. Non-baryonic matter resists Theta suppressors and raises the Sigma flag. |
| `CognicaoAparenteId` | int | yes | Brazilian cognition classification (SE/SA/IN/AA). Null until measured. |
| `PericulosidadeId` | int | yes | Brazilian dangerousness classification (1..9). Null until measured. |
| `MecanismoPrimarioId` | int | no | Main VISIBLE mechanism — the observable HOW of the phenomenon (e.g. transformation = THETA-C). |
| `MecanismoSecundarioId` | int | yes | Underlying mechanism, optional. Only accepts mechanisms flagged as a sub-nature, and OMEGA cannot have a THETA sub-nature — both rules enforced by TR_Anomalia_Validar_Mecanismos. |
| `IEIA_D_Base` | decimal(8,4) | yes | Anomalous Isotopic Enrichment Index for Deuterium, measured on the object itself. The human baseline is below 0.015%; above 0.1% indicates active use of the Theta layer. It is the central quantitative marker of the system. |

| `Status` | varchar(20) | yes | State of the RECORD: ATIVA, NEUTRALIZADA, DESTRUIDA. NOTE: the EM_PESQUISA value, used today, is a WORKFLOW state, not a catalog state — it moves to the classification pipeline once that exists (DECCO-BACKLOG, finding 6). |

| `UsuarioCriacao` | nvarchar(128) | yes | Filled with SYSTEM_USER by DEFAULT. In the baseline, Anomalia was the only table with user auditing; Instalacao and Operacao are born with it. The other baseline tables only have dates (DECCO-BACKLOG, finding 5). |
| `UsuarioAtualizacao` | nvarchar(128) | yes | Updated by TR_Anomalia_Update_Date with SYSTEM_USER on every UPDATE. |
| `InstalacaoContencaoId` | int | yes | Where the anomaly is physically contained: the most specific known facility (containment area or laboratory; otherwise, the site). Replaced the free-text SitioContencao (migrations 0002/0004). It is NOT a permission boundary: the anomaly is a global catalog, sliced by clearance; what is sliced by facility is Operacao. |
